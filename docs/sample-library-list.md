## 边界

样本库只用虚构内容，A 厂的文件只拿来参考结构，而且只新建、不改动任何已有文件。

- **全部虚构：** 厂名用澄川制药有限公司，人名、设备型号、品种参数也都是虚构的。每份文件页脚印「虚构样本，仅用于作品集演示，与任何真实企业无关」。
- **A 厂文件只读，只参考结构：** 包括文头表、章节顺序、文件变更历史表、四段式编号和记录模板的编法。正文、品种、人名、设备型号和厂名一律不复制，A 厂的品种也一个不用。章节口径用更通用的「目的 / 范围 / 职责 / 程序 / 相关文件 / 记录 / 变更历史」，不照搬 A 厂的版式。
- **只新建：** 文件只写进「03 样本文件库（虚构）」，重名就停下来，不覆盖。11/2 起按总控 D-09 移到原型仓库的 samples/，03 里只留替身。
- **药典只引版次和通则编号**（如「2025 年版四部通则 1105」），不摘录药典原文。
- **受访厂用代号：** 第一轮访谈记录里两家厂用的是真名，作品集和本仓库里一律写代号 A 厂 / B 厂。

## 澄川制药设定

澄川制药设定为约 300 人的外用非无菌制剂厂，和两家受访厂同类，这样场景和访谈证据才对得上。

| 项目 | 设定 |
| --- | --- |
| 剂型 | 乳膏、软膏，暴露工序在 D 级洁净区 |
| 品种（品种号） | 尿素乳膏（10）、克霉唑乳膏（11）、酮康唑乳膏（12） |
| 部门 | 质量管理部（QA）、质量控制部（QC：理化室、微生物室）、生产技术部、设备工程部、乳膏车间（甲班、乙班各一套文件夹）、仓储部、人力资源部 |
| 关键设备 | 乳化均质机 RH-300（现用）；场景一更换为 RH-500 |
| 文件管理方式 | OA 审批，扫描件放共享盘，Excel 台账，纸质受控副本 |
| 定期回顾 | 生效后 3 年（写在 SMP-WJ-001）；记录模板随母文件回顾 |
| 药典 | 2025 年版《中国药典》自 2025-10-01 起施行（[新华网](https://www.xinhuanet.com/health/20250326/06784315451047d8a2cf878db202b250/c.html)） |

## 场景覆盖

场景一修订 SOP-SB-021，影响清单应正好列出 9 份连带文件，对应产品定义里的成功标准“找全 9 份”。场景二的输入是药典通则 1105 修订，应列出 8 份。
